## 1. Objectives & Participant Selection

The objective is to quantify usability, cognitive load, and error rates among informal waste collectors with low textual literacy when using the Vernacular Low-Literacy Interface.

### 1.1 Participant Criteria
- **Target Count:** 10–15 informal collectors (*kabadiwalas*)
- **Literacy Levels:** Level 1 (Non-literate, relies on icons and spoken voice) to Level 2 (Semi-literate, reads numbers and simple native words)
- **Languages:** Native speakers of Marathi (`mr`), Hindi (`hi`), or Punjabi (`pa`)
- **Device Familiarity:** Owns or operates a touchscreen Android phone (JioPhone Next, Redmi, Samsung A-series)

---

## 2. Five Core Benchmark Tasks

| Task # | Task Description | Starting Screen | Target Success Criteria |
|---|---|---|---|
| **Task 1** | **Check Copper Scrap Price** | Home | Navigates to Prices, taps speaker icon to hear price in native tongue |
| **Task 2** | **Build & Submit Scrap Lot** | Basket / Home | Adds 2 items (e.g. Battery + Copper), views estimated payout, submits |
| **Task 3** | **Confirm Cash Handover** | Handover Screen | Verifies digital scale weight, confirms physical cash counted with GPS |
| **Task 4** | **Check & Settle Buyer Dues** | Earnings Ledger | Identifies debtor name and phone number, taps 'Mark Received (Cash)' |
| **Task 5** | **Trigger Safety Hub / SOS** | Safety Screen | Finds emergency helpline or hazardous battery handling guide |

---

## 3. Quantitative Evaluation Metrics

For each task, the following metrics are recorded using the **in-app Test Mode Stopwatch**:

1. **Time on Task (Seconds):** From prompt delivery to final confirmation tap.
2. **Task Completion Rate (%):** Successful completion without test proctor intervention.
3. **Error Count:** Incorrect button taps, backtracking, or misinterpretations.
4. **Assistance Requests:** Number of verbal prompts required from evaluator.
